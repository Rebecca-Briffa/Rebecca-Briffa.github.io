# Rebecca Briffa

Personal site for [GitHub Pages](https://pages.github.com/), in the same vein as a typical academic homepage: photo and details on the left, bio and highlighted work on the right.

## Add your photo later

1. Put a picture in this folder named `photo.jpg`.
2. In `index.html`, replace the placeholder circle with:

```html
<img class="photo" src="photo.jpg" alt="Portrait of Rebecca Briffa" />
```

## Fill in the text

Edit `index.html` and replace the placeholder title, intro, and “Highlighted work” items with your own.

## Publish on GitHub

Create a public repository named **`Rebecca-Briffa.github.io`**, push this folder to the `main` branch, then open:

https://Rebecca-Briffa.github.io
