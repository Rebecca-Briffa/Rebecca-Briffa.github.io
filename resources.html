Codes and pipelines

Public GitHub repositories for the solvers and MCMC pipelines I work with. The same late-time MCMC setup used for f(T) has also been applied to related models such as f(T, B).

  • GA–MCMC pipeline

    Genetic-algorithm discovery of dynamical dark energy w(a) with CLASS, Cobaya, and CLiENT.

    github.com/Rebecca-Briffa/GA-MCMC_pipeline

  • f(T) MCMC

    Late-time MCMC constraints on f(T) cosmology with cosmic chronometers, Pantheon+SH0ES, BAO, and RSD: solver, likelihoods, and data.

    github.com/Rebecca-Briffa/fT_MCMC

  • f(T, B) MCMC

    The same MCMC framework for f(T, B) cosmology with cosmic chronometers, Pantheon, and BAO.

    github.com/Rebecca-Briffa/fTB_MCMC

  • f(T) Boltzmann solver (CLASS)

    Teleparallel f(T) implemented in CLASS, so the model can be run end to end including CMB comparisons.

    github.com/Rebecca-Briffa/f_T_CLASS
